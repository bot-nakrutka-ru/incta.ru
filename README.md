# Incta.ru — статическая версия для GitHub Pages

Сборка создана из экспорта WordPress от 17 ноября 2026 года и оригинальной темы `instagram`. В ней **144 статьи**, **3 обычные страницы**, главная страница, архивы пяти рубрик, поиск и адаптивная верстка. PHP, WordPress и база данных для работы сайта не нужны.

## Как добавить скачанные 964 изображения

Изображения специально **не включены** в ZIP, чтобы не загружать их повторно. Установите их в точности в следующую папку уже распакованного сайта:

```text
incta-static/
├── index.html
├── assets/
├── wp-content/
│   └── uploads/
│       ├── 2021/
│       │   └── ...
│       ├── 2022/
│       │   └── ...
│       └── 2023/
│           └── ...
├── media_urls.txt
└── verify_images.py
```

Если после старого `download_images.py` у вас уже есть папка `wp-content/uploads`, **просто скопируйте эту папку** в новую сборку, сохраняя подкаталоги с годом/месяцем. Ничего перекачивать и повторно запускать `download_images.py` не нужно.

Проверьте полноту загрузки из корня новой сборки:

```bash
python verify_images.py
```

В ответе ожидается: `Найдено файлов: 964` и `Отсутствуют: 0`. Если обнаружены пропуски, имена появятся в `missing_images.txt`. Важно: без копирования фотографий картинки **не появятся** — их локальные ссылки уже проставлены и не обращаются на старый WordPress.

## Локальная проверка

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/`. Проверьте поиск в шапке, рубрики, любую статью, оглавление, карточки и отображение на телефоне. Страницы при этом не требуют WordPress и работают из локального статического HTTP-сервера.

## Как публиковать в GitHub Pages

1. Создайте репозиторий и загрузите **содержимое** папки `incta-static` (не папку целиком) в корень репозитория. `index.html`, `404.html` и `.nojekyll` должны быть в корне.
2. Откройте `Settings → Pages → Build and deployment`, укажите ветку `main`, папку `/(root)`.
3. Проверьте временный адрес GitHub Pages; только после проверки переносите основной домен `incta.ru` и настраивайте DNS по официальной инструкции GitHub.
4. После переключения проверьте `https://incta.ru/sitemap.xml`, `robots.txt`, несколько старых URL статей и `https`.

**SEO:** оригинальные адреса 144 статей, их содержимое, заголовки Yoast SEO, метаописания и канонические ссылки на `https://incta.ru/` сохранены. Добавлены Open Graph теги, карта сайта и 404. Выбранный домен важен: если вы НЕ переносите `incta.ru`, перед публикацией нужно заменить канонические/OG-URL, `sitemap.xml`, `robots.txt`, а также адрес в `404.html`.

## Как работает без WordPress

Поиск работает на JavaScript по заголовкам, рубрикам и полному тексту страниц. Меню, оглавление, кнопка «Поделиться» и смена советов работают в браузере. Опросы позволяют отметить выбор в текущем браузере; ответы **не собираются на сервере**. Новые комментарии, серверные формы и WordPress-плагины без бэкенда не работают. На публичных страницах технические уведомления об этом не показываются.

Данные главной страницы из ACF options не входили в XML, поэтому часть блоков восстановлена по действующему сайту и исходной теме, а не воспроизведена из настроек WordPress. Полный визуальный тест в браузере разных устройств следует провести до отключения старого хостинга.
